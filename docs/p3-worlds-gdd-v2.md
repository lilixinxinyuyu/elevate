## 3. 教育落差修正（Gemini 指出，必须改）

### G4 下册真核心 skill（不是"小数加减"那么简单）
- **数学**：分数（½ + ¼）、小数乘除、多边形面积、平均数、运算律
- **英语**：方位介词（on/under/next to）、量词（some/many/a few）、比较级、动词时态
- **语文**：阅读理解（提取信息）、段落表达、记叙文、错别字、近义词反义词

### 错位场景（v1 被打回）→ 重做（v2 才上）
| 学科 | v1 设计 | 问题 | v2 重做 |
|---|---|---|---|
| 数学/天平 | 学校教室解 □+3=7 | DragonBox 烂梗 + "学校上课不叫生活应用" | **物流中心**：货物平衡 + 重量分摊 |
| 数学/概率 | 警察局案件 | 压抑 + 枯燥 | **宠物店**：盲盒抽中概率 + 颜色分布 |
| 语文/对联 | 茶馆死记硬背 | 应试套皮 | **报社小编辑**：拿高亮笔圈出文章的错别字 / 语病 / 逻辑漏洞 |
| 英语/海关 | 机场对话 | 成人高频场景，10 岁不共鸣 | **我的房间**：方位介词 + 物品归位；**宠物店** ：动物特征描述 + 比较级 |

**v2 v1 vertical slice 只先做 1 个，不碰这些 → 验证 loop 后再扩**。

## 4. v2 Vertical Slice 详案：**和平小卖部**

### 4.1 视角 + 场景

```
   ┌──────────────────────────────────────────────────┐
   │   [门口] 🚪    [货架] 🏷️🥖🥛📦   [广告牌] 💰     │
   │                                                  │
   │   ┌─顾客 NPC──┐                                  │
   │   │  🧑 站着  │   < Camera 视角（柜台后看顾客）  │
   │   │  「我要 …」│                                  │
   │   └───────────┘                                  │
   │ ════════ 柜台木桌 ════════                       │
   │   [扫码篮]  [计算器]  [钱柜 - 1元/5角/1角/5分]    │
   │   🍎 🥖    [总价: ¥4.5]   🪙🪙🪙🪙              │
   └──────────────────────────────────────────────────┘
   ↑ Selena 看到的画面（第一人称柜台后）
```

- **R3F 固定机位**：camera 在 [0, 1.5, 0.6] 看 [0, 1.0, -2]，FOV 50
- 不要 OrbitControls，不要"走"——Selena 看到的就是柜台和顾客
- 顾客是 emoji + HTML overlay 头像（不用 VRM，省性能）
- 货架 / 计算器 / 钱柜 = 3-5 个 low-poly box（procedural，不依赖 OBJ 素材）

### 4.2 顾客触发的真互动（4 步必备）

#### 互动 A：扫码算总价（小数乘）
1. **操作物**：顾客桌上放 3 件物品 emoji + 标签价 (¥1.5 / ¥2.0 / ¥0.8)
2. **规则校验**：Selena 拖物品到"扫码篮"，篮上方实时累加总价
3. **场景反馈**：扫对 ✓ 物品变金色边框；扫错 ✗ 退回桌面 + 顾客挠头
4. **奖励**：扫完 → 总价显示 → +5 XP + 1 个"店面碎片"

#### 互动 B：找零（小数减）
1. **操作物**：顾客递 ¥10，应付 ¥6.3，钱柜里 1元/5角/1角/5分 钱币堆
2. **规则校验**：拖钱币到"找零托盘"，托盘上方实时显示当前金额
3. **场景反馈**：金额对 ✓ 钱币飞向顾客 + "谢谢"；多了/少了 ✗ 顾客摇头钱币退回
4. **奖励**：完成 → +5 XP + 1 个"店面碎片"

#### 互动 C：上货分类（数量 + 分数，扩展）
1. **操作物**：仓库箱里有混合的 12 个物品
2. **规则校验**：拖到 3 个货架（饮料/零食/日用）；每架要求"½ 是 X 类"
3. **场景反馈**：放对货架灯亮；放错灯灭 + 物品退回
4. **奖励**：装满 → 货架升级 ✨

### 4.3 主动建造系统（取代自动繁荣）

- 每 session 给 1-2 个"店面碎片"（招牌/盆栽/吊灯/海报/玩偶——盲盒掉落）
- 主入口 /worlds 有"**我的小卖部**"按钮 → 进装修模式
- 装修模式：Selena 拖装饰物到店面任意位置（drei drag controls）
- 摆放保存 → 下次进店面，看到自己摆的装饰
- 这是 Selena 表达自我的渠道，**核心情感连接**

### 4.4 小进定位（不再关 PIP）

- 小进站柜台**旁边**（VRM 全身，scale=1，固定位置）
- idle: 看店内动静，偶尔挥手
- Selena 答对：小进微笑 + thumbsUp 单次手势
- Selena 答错 3 次后：小进自动走近一步 + 头顶 ✋ 按钮"需要小进帮忙？"——点击才触发 Realtime Tutor
- **不破坏沉浸**：默认场景内反馈，求救是主动行为
- 红熊猫站小进脚边 / 偶尔追蝴蝶（绕小进 1m 圆周）

### 4.5 性能预算（GPT-5.5 红线）

- iPhone 12 baseline，30 fps 最低
- 首包 JS+静态 ≤ 5 MB（OBJ 0 个，全 procedural）
- DPR `[1, 1.5]`
- `frameloop="demand"` 静止时不重绘
- VRM 11MB 走 lazy import，loading 期间 procedural 占位
- 没 shadow，没 envmap，hemisphere + 1 directional 灯就够

## 6. 验收标准（必备，AI 都强调）

每个 mini-game 上线前必过：

1. **操作物有物理感**：拖动有惯性 + 阻力，放置有"咔哒"音
2. **规则校验即时**：拖到正确区域立刻反馈，不要"提交"按钮
3. **场景反馈丰富**：对/错都有 NPC 动作 + 物品变化 + 微音效（不是 modal popup）
4. **奖励可见**：+XP 飞向 HUD + 店面碎片掉落动画 + 进度环填充
5. **失败可恢复**：错了能继续试，不强 modal 教学
6. **Selena 试玩 5 分钟内能独立完成 3 单**：5 分钟 = 真用户验证窗口
