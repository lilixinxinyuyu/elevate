## 答题格式：sort_ladder（排序题）

**特点**：给若干项让孩子按指定顺序拖到正确位置（升序 / 降序 / 时间顺序 / 故事顺序）。前端用 sort_ladder 或 sentence_shuffle 模板。

### 适用场景
- **数学**：小数大小排序、长度 / 重量比较排序、温度从低到高
- **语文**：句子排序（按事件先后）、古诗诗句顺序、词语按结构分组排序

### 必填字段
```json
{
  "question_format": "sort_ladder",
  "play_as": "sort_ladder",
  "options": [
    { "id": "A", "text": "0.45" },
    { "id": "B", "text": "0.5" },
    { "id": "C", "text": "0.405" },
    { "id": "D", "text": "0.504" }
  ],
  "answer": {
    "type": "choice",
    "value": "C,A,B,D"
  }
}
```

### 设计要求

#### 1. 排序项数
- 3-5 项（2 项不算排序，6+ 太繁琐）

#### 2. 答案表示
- `answer.value` 是按目标顺序连接的 id 字符串（逗号分隔）
- 如升序则从小到大列出

#### 3. 题干必须明确方向
- ✅ "把下面小数从小到大排列"
- ✅ "按时间顺序排列下面句子"
- ❌ "排一下" / "整理一下"

#### 4. 项目之间区分度
- 数学排序：相邻两项至少要明显不同（不要 0.499 / 0.5 / 0.501 让孩子心算崩）
- 语文句子排序：每句的时间 / 因果关系要清晰

#### 5. 不能有"并列"项
- 任何两项必须有明确顺序（不能 0.30 和 0.3 都对）

### 数学排序专用要求
- 数字类型一致（不要混 1/2 和 0.5）
- 单位一致（不要混 米 和 厘米）

### 语文句子排序专用要求
- 4-5 个句子能拼一个完整段落
- 必须有"事件先后" / "因果链" / "起承转合" 等明确逻辑
- 不要让孩子靠"哪句更通顺"猜（必须有客观顺序）

### 时间（estimated_time_seconds）
- 3 项：25s
- 4 项：35s
- 5 项：45s

### ⛔ 禁止
- 项数 < 3 或 > 5
- 任意两项可互换（无明确顺序）
- 数学单位混
- 语文句子没有清晰逻辑
