## 为什么放弃 Atelier

Bruce 反馈精准（v0.32.9 atelier ship 后）：

> "你现在加的这几个东西，就是多了中间的一层外壳，里面的话还是一样的做体的过程。这些体的话，也没有跟实际的主题结合到一起。"

确实。Atelier 只是给老的 train 流程套了个壳：
- ❌ 玩法 = "点 portal → 进 Train.tsx → 一个一个 popup 题"
- ❌ 题目跟 realm 主题没真结合（折扣街给的还是随机小数题）
- ❌ 视觉只有 React 卡片，"3D 小进" 只在 hub，drill 时退化成传统 modal

## 为什么 City 是对的

Bruce 原话拆解：
1. **数学天然嵌入城市生活**：银行计算 / 公交时刻 / 警察统计 / 超市单价折扣 — 不用强行编故事，每个建筑的"职能" = 一类数学题
2. **可成长**：小村庄 → 乡镇 → 县城 → 城市 → 大都市，跟小学 → 初中 → 高中 → 大学的认知扩展曲线契合
3. **跨学科**：城市概念能容纳数学之外的语文（图书馆 / 公告牌）、英语（外国游客）、艺术（公园 / 美术馆）— 一套世界观打 Selena 整个学龄

## 核心原则

1. **3D 场景就是游戏**，不是"hub + 旧 drill"两段式
2. **每个建筑有专属玩法**，玩法跟建筑职能强绑定（银行 ≠ 公交 ≠ 警察局）
3. **题目隐性嵌入场景**：客户排队、车次表、案件地图 — 数学是工具，不是任务清单
4. **可视化成长**：玩越多，小镇越繁荣（更多建筑、更多 NPC、更多车流），是看得见的进步
5. **小进是镇长 / 导师**：一直陪伴（PIP 或同框），不是空降 NPC

## V1 小村庄 (Phase 1) — 4 个建筑 + 街道

> 故事背景：Selena 跟小进搬到一个迷你村庄，需要帮村民解决日常问题。所有交互都在 3D 场景里完成（无 modal popup）。

              │                            │
              │   ┌──────┐                 │
              │   │ 🏦   │  ┌──────┐       │
              │   │ 银行  │  │ 🚌    │       │
              │   └──┬───┘  │ 公交站  │       │
              │      │      └──┬───┘       │
              │   ═══════════════════════  │ ← 主街道
              │      │            │        │
              │   ┌──┴───┐   ┌────┴──┐    │
              │   │ 🏪  │   │ 🏫     │    │

              └───────────────────────────┘

R3F isometric / 俯视 30° 视角，地面 plane（草地纹理），主街 box（柏油），4 建筑用 low-poly box + emoji 标牌 + 灯光。

### 4 建筑各自玩法（**完全在 3D 场景内**，不是 popup）

#### 1. 🏦 银行 — 找零台
- 进银行 → 3D 银行内景：柜台 + 一只虚拟客户站着等
- 客户头上浮"我要存 ¥X.XX"或"应付 ¥A.AA, 客户给了 ¥B.BB, 找零多少？"
- 柜台上有 3D 钱币堆：1元 / 0.5元 / 0.1元 / 0.05元（不同 emoji 或圆柱体）
- 玩家**拖钱币到中央托盘**，托盘上方实时显示总和
- 总和 = 目标 → 钱币飞向客户 → "谢谢小进！" → 下一位客户
- 数学内容：**小数加减 / 找零 / 单位换算**
- 完成 N 个客户 = 一个"工作日"，加灵感 + 解锁更高难度

#### 2. 🚌 公交站 — 调度员
- 进公交站 → 3D 站台 + 时刻表大牌
- 一只虚拟乘客走来："我要去 X 地，下班车几点开？要坐多久？"
- 时刻表是 SVG 网格，玩家点击查找 → 输入答案
- 或：玩家**画一条路线**（点起点-中转-终点）→ 自动算总时间 + 距离
- 数学：**速度 × 时间 = 距离 / 时间表读图 / 相遇问题**

#### 3. 🏫 学校 — 黑板课堂
- 进学校 → 3D 教室，黑板上有等式如 "□ + 3 = 7"
- 玩家**拖数字方块**到方框补全
- 高级关：天平秤可视化等式两边平衡（左加 → 右也要加）
- 数学：**字母表示 / 方程 / 等式性质**

#### 4. 🏪 小卖部 — 购物车
- 进小卖部 → 3D 货架，物品有标签价（小数）
- 客户："我要 3 个 X, 2 个 Y, 总共多少钱？" / "我有 ¥10 能买什么？"
- 玩家**拖物品到购物车**，篮子右上实时累计
- 数学：**小数乘 / 单价×数量 / 折扣**

### 小镇主入口（TownHomePage）

R3F Canvas 俯视小村庄，所有建筑可见 + 路灯轻微脉冲。Xiaojin 在主街上 idle（用现有 Mascot3D，小尺寸）。

- Hover 建筑 → 标牌发光 + 显示"今天有 3 个客户等待 🏦"
- Click 建筑 → 镜头平滑推进 → 切到建筑内景场景
- 完成场景 → 镜头拉回 → 看到 +N 灵感 + 小镇某处可能出现新元素

### 小镇成长 (Town Size Progression)

```
0-30 灵感：迷你村庄（4 building V1）
30-80：村庄长出邮局 + 公园喷泉（5 个 building, +统计/概率玩法）
80-200：升级乡镇 — 加图书馆 + 警察局 + 诊所（7-8 building, 跨学科扩张）
200+：县城（更高难度数学场景）
```

每升级一档：
- 镜头拉得更远（小镇变大）
- 新建筑动画从地里 "长出来" + Xiaojin cheer + 庆祝条
- 旧建筑解锁更高难度模式
