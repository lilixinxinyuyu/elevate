## 答题格式：drag_drop（拖拽配对）

**特点**：左右两列卡片，孩子拖左边某项到右边对应位置（或点击连线）。前端用 pair_match 模板（语文）或自定义拖拽模板（数学）。

### 适用场景
- **语文**：近反义词配对、量词配对、多音字-语境配对、汉字-拼音配对、字-部首配对
- **数学**（少用）：单位换算配对（"1 米 = ___" / "100 厘米 = ___"）、图形-公式配对

### 必填字段
```json
{
  "question_format": "drag_drop",
  "game_data": {
    "kind": "pair_match",
    "leftItems": [
      { "id": "L1", "text": "高兴" },
      { "id": "L2", "text": "美丽" },
      { "id": "L3", "text": "快速" }
    ],
    "rightItems": [
      { "id": "R1", "text": "悲伤" },
      { "id": "R2", "text": "丑陋" },
      { "id": "R3", "text": "缓慢" }
    ],
    "correctPairs": [
      ["L1", "R1"],
      ["L2", "R2"],
      ["L3", "R3"]
    ]
  },
  "answer": {
    "type": "multi_step",
    "steps": [{ "step_id": "pairs", "expected": "L1-R1,L2-R2,L3-R3" }]
  }
}
```

### 设计要求

#### 1. 配对数量
- 3-5 对（2 对太少没挑战，6+ 太繁琐）
- 左右两列数量必须相等

#### 2. 干扰防呆
- 左右各列不要重复（同一个 right 不能匹配多个 left）
- 不要让答案"显然"（如左 "苹果" 右 "fruit" + "horse" + "car"，过于明显）
- 选项之间应有真实辨析价值

#### 3. 适合 4 年级的难度
- 词的概念在课内（不超纲）
- 不要混入两类题（既考近反义词又考量词）— 一道题专心一类

#### 4. 题干（stem）写法
- "把左边的词和右边的反义词连起来" / "把汉字和正确的部首拖到一起"
- 避免"输入" "选填" 等模糊指令

### ⛔ 禁止
- 答案 multi-correct（一个 left 匹配多个 right）
- 拖到不存在的 right slot
- 配对数量不一致

### 时间（estimated_time_seconds）
- 3 对：30s
- 4 对：40s
- 5 对：50s
