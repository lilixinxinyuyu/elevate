# Hub v7 主界面设计规格 (build spec)

> 2026-05-21 定稿。来源: Bruce 看过 `/math/hub-v7-preview` 的反馈 + 8787(资深游戏设计师) /
> 8788(游戏策划师) 双角色 review 一致结论。本文件 = 后续逐步实现 v7 的施工蓝图。
> 约束: **1 个娃 (Selena), 距期末 39 天** → 主界面必须 **5 秒内把人推进"今天的练习"**, 不能是 time-sink。

---

## 0. Bruce 反馈 → 要解决的问题清单
1. 4K 屏只占中间 ~50%, 要 scroll, **不是单屏铺满**; 顶部还有**老的全局菜单**; 内容**互相覆盖**。
2. 顶部"生成角色"按钮**没道理** —— 同学**只在第一次进入配置一次, 之后锁定**, 不允许频繁重生。
3. 顶部该放: **各 minigame 入口 / 6 单元技能地图状态**。
4. 缺真游戏的元素: 进来**怎么玩**、该**看到什么**(landing 统计)、怎么**轻松进各玩法/场景**拿经验、**正反馈**; 主界面**角色成长**要有**正反馈/动效/小装饰道具** → 努力后的获得感。
5. 画面 2D 卡通 vs low-poly 仿3D? (考虑之后真 3D 环境装饰迁移)

---

## 1. 布局: 边缘锚定 + 单屏铺满 (原神 / Roblox 式)
- **背景**: 场景图 `object-fit: cover` 铺满整个视口 (含 4K / 超宽屏), 不留空。整页 `h-[100dvh] w-screen overflow-hidden` (**单屏, 不滚动**)。
- **删掉本路由的全局顶部菜单**: HubV7 作为全屏沉浸场景, 不套常规 Layout 的 nav (要么 route 在 Layout 外, 要么该 route 隐藏 nav)。修复一切覆盖/重叠。
- **三栏边缘锚定** (面板钉边, 中间留给角色):
  - **左 (today)**: 今日任务栈, ≤3 张卡。每张带**奖励预览** ("+80 XP · +1⭐ · 分数熟练度↑") + 一个 **Start** 按钮。
  - **中 (avatar)**: 全身 2D 立绘站发光平台上, idle 动画; 平台四周是**已赚到的装饰道具**(见 §3)。角色脚下一个**巨大脉动主 CTA "开始练习 ▶"** (5 秒进练习的黄金按钮)。
  - **右 (progress / landing 统计)**: 等级 + XP 条; 段位 (校→区→市→省→国); **期末倒计时 (39 天)**; 最弱 3 技能; 连胜 streak; **下一解锁预告** ("再完成 2 个今日目标 → 解锁 [市级斗篷]")。
- 小屏 (手机): 三栏 reflow 成 顶 HUD / 中角色 / 底任务+CTA (已有 mobile reflow 基础, 保留)。

## 2. 顶部 bar / 导航 (替换"生成角色"按钮)
- **删除生成角色按钮** —— 角色第一次 onboarding 配置后**锁定 = 永久身份**。
- 顶部改成**世界地图 ribbon**: 6 单元**技能地图**状态 (锁 / 学习中 / 掌握 / 薄弱 四态) + 各 **minigame 入口**, 做成**岛屿 / 节点**视觉, 不是网页按钮。
- **模式入口** (8788 建议, 但别让娃选太多 —— "今日"自动选):
  - **Quick Practice** 最快路径, 自适应抽薄弱点 (= 主 CTA 指向)
  - **Boss Quiz** 期末风格混合卷 (= mock_exam, 已修 from_test 优先)
  - **数学 minigame / 语文 minigame**
  - **6 单元技能地图** (状态总览)

## 3. play → reward → growth 闭环 (主界面上可见的正反馈)
- **登录瞬间**: XP 条从昨天的值**叮叮往上跳** + 音效 (把已积累的努力可视化)。
- **做完练习回到主界面**: 角色**发光 + 欢呼 pose** + 小熊猫副手反应 + **XP 飞进等级条**。
- **平台道具系统 (核心获得感, 两位都点名)**: 完成一个单元 / 里程碑 → 平台上**永久出现一个动画小道具** (按职业: 探险家望远镜 / 法师魔法书 / 科学家仪器 / 灯笼 / 水晶 / 绿植…)。**靠练习里程碑赚取, 不是随机买**。努力**可视化累积** —— 每天回来都能看到自己攒的东西变多。
- **升段**: 沿用已做的 CharacterTierUpModal (旧立绘→白光→新立绘), 是最大的正反馈节点。

## 4. 画面技术: 保持 2D 卡通 (2.5D 分层视差), **不要 low-poly 仿3D**
两位**一致**。理由:
- 角色已是 **2D anime 立绘 (情感核心)**; 仿 3D low-poly 会**打架 / 显廉价**。
- 2D 道具 / 背景**更快更省更可控**。
- **不堵未来真 3D 路**: 现在做 **2.5D 分层场景** (视差背景 + 平台 + 道具 + 光效); 之后真 3D 环境装饰可作为**独立场景物件**叠在 2D 角色后面/周围迁入。分层结构天然兼容。

## 5. 实现顺序 (每步可单独 dev-verify + ship, 不一次性大改)
1. **单屏铺满 + 删旧顶部菜单 + 修覆盖** (布局骨架; 背景 cover, h-100dvh, 三栏边缘锚定)。
2. **删生成角色按钮 → 顶部换 minigame/技能地图 ribbon** (节点视觉 + 路由到各模式)。
3. **脚下主 CTA "开始练习" (脉动) + 左今日任务(带奖励预览) + 右进度(含 39 天倒计时/最弱技能/下一解锁)** 三栏接真实数据。
4. **平台道具系统**: 完成单元 → 平台永久长出职业道具 (数据 + 渲染 + 入场动画)。
5. **登录 XP tick 动效 + 做完题角色欢呼/XP 飞入** (juice)。
6. (Bruce/Selena 试用 OK 后) flag-flip 设默认 —— **保留给 Bruce 拍板** (task #22)。
