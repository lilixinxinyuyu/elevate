## 题型：poem_cloze（古诗补字 / 灯笼填字）

⏱️ **答题时间**：`estimated_time_seconds: 28`

把课内古诗（或经典段落）抠掉 1-3 个关键字，让 Selena 从字池里挑字填回。**核心训练**：古诗背诵、易错字、形近字辨认。前端是「元宵灯笼」场景（C1 古诗拍灯笼 cluster）。

### 玩法（前端）

展示诗题 + 作者 + 诗句（缺字处显示「?」），底部一排字池（正确字 + 干扰字）。点字填空，全部填对即过关。

### stem 必须格式（前端靠它解析诗题/作者）

stem 一律写成：`把字塞进{作者}《{诗名}》的空格里：`
- 例：`把字塞进杜牧《江南春》的空格里：`
- 作者可省略（写成 `把字塞进《诗名》的空格里：`），但**有作者更好**。

### 必须字段

```json
{
  "game_type": "poem_cloze",
  "question_format": "single_choice",
  "cognitive_level": "recall",
  "ability_dimension": ["accumulation"],
  "estimated_time_seconds": 28,
  "stem": "把字塞进杜牧《山行》的空格里：",
  "game_data": {
    "kind": "poem_cloze",
    "template": "远上寒山石径斜，白云生处有人___。\n停车坐爱枫林晚，霜叶红于二月___。",
    "blanks": ["家", "花"],
    "pool": ["家", "花", "村", "霞", "亭"]
  },
  "options": [],
  "answer": { "type": "choice", "value": "__game_correct__" },
  "solution_steps": ["远上寒山石径斜，白云生处有人家。", "霜叶红于二月花——把红叶比作二月的春花。"],
  "feedback_correct": "灯笼亮了！这两个字是这首诗的题眼。",
  "feedback_wrong": "再读两遍，注意押韵的字。",
  "tags": ["ai_generated", "poem_cloze", "古诗"]
}
```

### game_data 规则（铁律）

- `template`：诗句原文，把要填的字换成 `___`（**三个半角下划线**）。多句之间用 `\n` 换行。
- `blanks`：按 `___` 从左到右、从上到下的出现顺序列出**正确字**。数量必须等于 template 里 `___` 的个数（1-3 个）。
- `pool`：包含**所有 blanks 的字** + 2-3 个干扰字（形近 / 同韵 / 易混），打乱顺序。pool 长度 = blanks 长度 + 2~3。
- 干扰字要有迷惑性：用形近字（如 "未/末"）、同音字、或意思接近但用错的字。
- ❌ 禁止 blanks 里有重复字（同一个字挖两个空会导致前端判定歧义）。

### 选诗范围（G4B 下册优先）

人教版四年级下册古诗：宿新市徐公店、四时田园杂兴、清平乐·村居、芙蓉楼送辛渐、塞下曲、墨梅、独坐敬亭山、望洞庭、清明、江南春、惠崇春江晚景、滁州西涧、忆江南。也可用四年级学过的其他经典唐诗宋词。

### ❌ 禁止

- template 不带 `___`，或 `___` 个数与 blanks 不符
- pool 缺少某个正确字
- 用生僻、超纲的古诗（必须是小学常见篇目）
- answer.type ≠ "choice"（固定填占位 `__game_correct__`，判分走 game_data）
