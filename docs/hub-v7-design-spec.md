## 🎯 核心收获 (两位一致的最关键判断)
**现在的 v7 是"功能仪表盘 (Dashboard)", 必须改成"游戏指挥中心 (Command Center / Lobby)"。**
仪表盘把所有功能平铺 → 选择瘫痪、像学习 App; 指挥中心用视觉层级 + 反馈(juice)告诉玩家:
"你是谁、你现在多强、接下来**只需点这个发光按钮**"。

> 检验标准 (planner 原话): **"Selena 现在最应该点哪里? 5 秒内答案若不唯一, 这个 Home 就失败了。"**

## 1. 唯一主干道: 动态主 CTA (P0, 最大改动)
- 脚下**唯一巨大发光呼吸按钮**, **不叫死板的"开始练习"**, 而是**绑定每日三环, 自动指向下一环**:
  - `今日 1/3 · 速算热身 6 分钟 ▶` → 完成 → `今日 2/3 · 错题营(因为昨天路程问题错 3 题) ▶` → `今日 3/3 · 期末 BOSS ▶` → 三环闭合后变 `自由探索 / 模拟卷`(动效减弱)。
- **不让她选题**: 进去由 SRS + 薄弱技能 + 考试倒计时**自动组卷**; 每局 5–8 分钟。
- **任务因果**: CTA / 熊猫要说明**为什么**做这个 ("昨天'路程问题'错 3 题 → 今天复活它")。
- **奖励预告**: 按钮/卡上写"做完马上拿什么" (`+80 XP · +1⭐ · 分数熟练度↑`)。

## 2. 视觉中心: 角色 + 熊猫 + 氛围 (P0)
- 角色立绘占**屏幕 ~50% 视觉权重**, 站发光平台, 待机呼吸/粒子(哪怕不能动也要星空飘落+平台呼吸灯)。
- **熊猫🐼 = 大厅向导/嘴替**: 每日**对话气泡**驱动一切 (回顾"昨天相遇问题完美击破" / 提示"5 道错题僵尸复活了" / 红点)。不是静态图标。
- **39 天情绪曲线** (氛围随期渐变, 见 §6)。

## 3. 边缘锚定的次级系统 (P1, 视觉低于 CTA)
- **左上 HUD (P0)**: 名字 + 段位 icon + **实体 XP 槽(看得到差多少升级)** + **连胜🔥 streak**(强留存钩子)。
- **右上 (P0)**: 期末倒计时做成**"史诗任务倒计时"**(决战 39 天, 不是焦虑钟) + 一个**小四维雷达**(点开才放大, 不平铺数值)。
- **左右屏幕边缘竖排精致 icon (P1)**: 技能星座图(有可点亮星星时发光) / 模拟卷 / minigame 街机厅 / 星海工坊 / 奖杯墙 / 错题复习(有到期亮红点)。
  → **这就是"顶部模式入口"该去的地方** (不是顶部一排 —— 见 cut-list)。

## 4. 返场即领奖台 (P0, 现在完全缺) — 练完回 Home 必须三层反馈
1. **即时**: XP **缓动 1.5s 涨满 + 升调"滴滴"音 + 升级时屏幕轻震/白闪**(游戏成瘾核心物理反馈); 三环进度推进; 星星点亮。
2. **成长**: 能力雷达某维 +1; 技能星座一颗星从 CTA **飞入**左侧 icon(震动+星光粒子); 薄弱→学习中。
3. **归属(努力落在"空间"里, 否则获得感断裂)**: 角色说一句话; **平台/场景新增小装饰** ——
   每做完一套模拟卷 → 平台多一块"真题符文"; 连续 3 天闭三环 → 角色脚下常驻"专注光环";
   宝箱进度 +。**全是 2D 叠加贴图/特效, 不重新生成 AI 立绘 → 成本极低反馈极强**。
4. **三环闭合 → 今日结算卡**: 做了多少题/准确率/复活哪些错题/距下段位还差多少/明天挑战什么。

## 5. 成长可视化 (P0): 段位太慢, 要中间反馈
- 5 段位平均 1–2 周才升一段 → **不够频繁**。补: ①光环/特效 ②平台符文 ③"下一段位距离"明确文案
  (`再完成 4 天三环 → 升【区级】新装`), 不只靠 chevron。
- 升段仍走已做的 CharacterTierUpModal(旧立绘→白光→新立绘), 是最大正反馈节点。

## 6. 39 天分阶段 (P1): Home 文案/氛围/BGM 随期变
- **39–25 天**: 补基础 + 点亮技能; 氛围轻松冒险风。
- **24–10 天**: 错题复活 + 单元攻坚; 背景变深、加鼓点; 熊猫台词转鼓励。
- **9–1 天**: 模拟卷 + BOSS + 稳心态; 界面转红/金、激昂战歌, 主 CTA 变"最终试炼" → 考试日是**屠龙不是受刑**。

## 7. 统计分两套 (P1)
- **给娃 (Home 上)**: "我变强了 / 点亮了 / 快换装了" —— 只看正向成长。**砍掉照片级数值报表**。
- **给爸爸 (单独家长页)**: 覆盖率 / 薄弱点 / 预测分 / 复习节奏。**别放娃的主界面**。

## 8. FTUE 首次进入 (P0): 5 秒法则 = 立人设 → 明确危机 → 给第一把武器
1. 选职业×性别 → 一道光柱砸平台, 立绘生成出现。
2. 熊猫气泡: "你觉醒了! 距【期末大魔王】39 天, 先测你的魔力!"
3. **UI 全隐藏**, 只剩 角色 + 倒计时 + 脚下唯一狂闪 CTA: **"能力诊断(开始测试)"**。
4. 测完回大厅 = **juice 爆发**: XP 唰满升级、连胜🔥点亮"1"、左右系统 icon 叮叮逐一解锁飞入 → 这就是"努力后的获得感"。
- **渐进解锁(隐藏=奖赏)**: 星海工坊等不必第一天全露, 完成首个 3 天连胜再隆重解锁。

- **顶部一排模式入口** → 砍掉横排, 移到**左右边缘竖排 icon / 背景星门**, 视觉低于主 CTA。(我上轮 step② 的顶部 ribbon 已据此**回退**。)

## ✅ 画面技术 (上轮已定, 不变): 2D 卡通 (2.5D 分层视差), 不 low-poly
角色是 2D anime 情感核心; 仿 3D 会打架显廉价; 2.5D 分层(视差背景+平台+道具+光效)更省更可控,
且未来真 3D 装饰可作独立场景物件叠进 → 不堵 3D 路。

# 🧠 v4 心理学设计哲学 — 荣誉/成就/攀比 (Bruce 2026-05-22 指导思想)

> Bruce: 充分利用荣誉感/成就感/攀比心 + 游戏心理学 + 教育心理学, 让 Selena**总想多做一点、主动补薄弱**。
> gemini-3-pro(设计师) + gpt-5.5(策划师) 双咨询(含教育心理学), **高度一致**。
> **核心哲学: 把掌控感还给孩子 —— 她不是被期末追着跑的苦命小学生, 而是检修装备/提升雷达、准备打最终 Boss 的王牌指挥官。成长镜像 > 排行榜; 薄弱修复荣誉 > 题量奖励; "我能赢"的证据 > 紧张。**

## 三大杠杆 → 机制 (挂已有系统)
- **荣誉感 (SDT 胜任力 + 身份认同)**: 错题本重命名"装甲修复舱"; 有薄弱点时角色某件装备"战损/暗淡", 清 SRS → 装备发光 + 解锁段位专属"高光待机动作"。荣誉是"我修复了短板"不是"我做了100题"——保护自尊。职业称号女性友好(星际法师/侦探队长/语言守护者/数学工程师)。
- **成就感 (目标梯度 + 蔡加尼克效应)**: 雷达"突破临界点"——某维快到下一关口(78→80)时该顶点心跳高亮; 每日三环留"半环"专攻最接近突破的维; CTA 写"再修复1个漏洞就达 A 级"不是"再刷10题"。频繁看到"我真变强了"。
- **攀比心 (社会比较理论, 单用户=安全向上比较)**: 段位天梯 + 木桶效应("计算已省级, 几何还校级, 拖后腿"→主动补最弱)。

## 单用户健康"攀比"(没真同学)
1. **影子竞速 / 过去的自己**: 雷达叠 7 天前 Selena 虚线轮廓 + "准确比上周+15%"; 限时练习侧栏"上周的你"进度影子。**自我超越是最健康的攀比**(自我效能感)。
2. **AI 影子对手 (训练伙伴, 非羞辱型)**: 分数略高她 5-10%(最近发展区, 够得着); **赢的条件必须含补薄弱**(打败影子需修复 2 道错题)。
3. **AI 学姐(雅典娜)**: 永远高一段位的友好引路人, 偶尔发通讯提示高频考点。
4. 班级百分位**慎用**: 有真数据也只显区间("前 30-40%"), 绝不显具体同学。

## ❌ 反面教材 (心理学底线, 必避免)
- 🚫 **断崖连胜清零** → 完美主义娃会"破罐破摔"。改: **连胜冻结卡/请假条**(XP 兑换), 合法休息不否定努力。
- 🚫 **红色警报/羞耻化错题** → 考试焦虑、逃避错题区。改: **蓝/紫色** + "待回收的能量/可提升区", 中性"叮"不是警报"滴滴"。
- 🚫 **无底洞刷题** → 认知疲劳、兴趣透支(38 天是马拉松)。改: **每日最佳量后收益衰减** + "引擎冷却, 去看课外书/休息"(得不到的永远在骚动 → 明天更想来)。
- 🚫 **只奖励题量** → 诱导空刷。必须奖励**薄弱修复 / 复盘 / 稳定性**。

## 🏅 38 天 ROI 最高的 3 个 (先做这 3 个 — 两位共识)
1. **薄弱点 Boss 化**: 薄弱知识点→可击败怪("分数应用·迷雾兽"/"粗心大魔王"), 血量挂错题数/SRS, 击败=清薄弱。**外部化叙事**(不是"我笨"是"有怪捣乱")→ 直接漏斗进补薄弱, 去羞耻化。最高 ROI。
2. **影子对战 / 过去的自己**(雷达叠 7 天前轮廓 + 进步率): 解决单用户攀比 + 安全不伤自尊, 肉眼可见成长。挂雷达/XP/段位。
3. **每日三环 = 必胜 + 薄弱修复 + 荣耀挑战**: ①今日必胜(10-15min 保底启动) ②薄弱修复(系统荐) ③荣耀挑战(可选, 给装饰/称号碎片)。小步成功+行为启动, 既保证每天开始又给"想多做"的出口, 防无限刷。
(+ 低成本高回报: 期末倒计时→**星际航线图** 38 跃迁节点分阶段, 把时间焦虑重构成每日前进一步。)
