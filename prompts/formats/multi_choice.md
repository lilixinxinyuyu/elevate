## 答题格式：multi_choice（多选）

**特点**：≥ 2 个正确选项，其余是干扰。前端用 clue_finder 模板呈现（线索挑选）。

### 必填字段
```json
{
  "question_format": "multi_choice",
  "options": [
    { "id": "A", "text": "三角形内角和 180°" },
    { "id": "B", "text": "正方形是特殊的长方形" },
    { "id": "C", "text": "锐角三角形有两个锐角" },
    { "id": "D", "text": "等边三角形是特殊的等腰三角形" }
  ],
  "answer": { "type": "choice", "value": "A,B,D" }   // 逗号分隔，按字母排序
}
```

### 何时用 multi_choice
- 概念辨析"全选正确的"
- 判断对错从一组"全部为真的命题"中挑出（语文阅读多选）
- "下列哪些 X 正确" 风格题

### 设计要求
- ≥ 2 个正确，**不要全选 4 个**（区分度太低）
- 不要 1 个正确（那应该用 single_choice）
- answer.value：所有正确选项 id 按字母升序逗号分隔（"A,B,D" 而非 "B,A,D"）
- 错误选项必须是 **常见误解**（不是显然荒唐）

### ⛔ 禁止
- 4 年级数学题不建议用 multi_choice（认知负担大）。除非真有 ≥ 2 个正确答案的题（如"哪些是钝角三角形？"），否则改 single_choice。
